
# Coding Standards & Conventions

## Tech Stack
- Language: Lua 5.1+ (Neovim API)
- Plugin Manager: lazy.nvim
- Testing: plenary.nvim test framework

## Code Quality Rules
- Type Safety: Use `---@param` and `---@return` EmmyLua annotations on all public functions
- Complexity: Keep functions under 20 lines. If longer, extract helpers
- Naming: 
  - Modules: PascalCase (`MyPlugin.lua`)
  - Functions: snake_case (`setup_server`, `get_buffers`)
  - Private functions: prefix with `_` (`_validate_config`)
  - Constants: UPPER_SNAKE_CASE (`MAX_RETRY_COUNT`)
- Documentation: EmmyLua doc comments for public API. Omit for private helpers unless logic is non-obvious
- Testing: Write tests using plenary.nvim `describe`/`it` blocks after new features or fixes

## Neovim-Specific Conventions
- Use `vim.api` functions over legacy `vim.cmd`/`vim.fn` whenever possible
- Prefer Lua tables over Vimscript data structures
- Keymaps: `vim.keymap.set` with explicit `{ noremap = true, silent = true }` unless remapping is intentional
- Autocommands: Use `vim.api.nvim_create_autocmd` with `group` parameter to prevent duplicates
- User commands: `vim.api.nvim_create_user_command` over `vim.cmd("command ...")`
- Buffer options: Use `vim.bo[bufnr]` and `vim.wo[winid]` for scoped options
- Always check `vim.fn.has("nvim-0.10")` or similar for version-dependent features

## Plugin Configuration Style
- Return a lazy.nvim spec table: ` M = { "author/plugin", opts = {} }  return M`
- Use `opts` over explicit `config` functions when possible
- Dependencies declared explicitly in spec, not implicit
- Lazy-loading triggers: `event`, `keys`, `cmd`, `ft`—be specific, not `VeryLazy`

## Workflow Rules
- Configuration: One plugin per file in `lua/plugins/`. No monolithic config files
- Refactoring: When modifying existing plugin configs, minimize diff churn—change only what's requested
- Never create new configuration files in root; use existing XDG-compliant paths
- Commit messages: Conventional Commits format, imperative mood, Neovim scope prefix:
  - `feat(completion): add LuaSnip integration`
  - `fix(lsp): resolve nil buffer in on_attach`
  - `chore(keys): rebind leader shortcuts for consistency`
